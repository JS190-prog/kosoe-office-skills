# 금융영업본부 공통 팩

- 상속: 전사 `koscom-hwp-report` · `ppt-master`(koscom-chevron) · `koscom-webslide` · `kosoe-illustrations`. 전사 지침은 그대로 따른다.
- 고정 문구(`blocks`)는 글자 그대로 넣는다: 회사 소개, 유의 사항.
- 검수: 유의 사항 문구 필수, `대외비`·`내부 검토용` 표기 금지(대외 문서).
- 결재라인: 담당 → 팀장 → 본부장.
