- 형식: PPT
- 구성(이 순서와 제목 그대로): 회사 소개 → 고객 과제 → 서비스 제안 → 레퍼런스 → 일정·비용

## 고정 문구(글자 그대로)
- 회사 소개: 코쇠금융IT는 자본시장 인프라를 함께 만들어 온 금융 IT 전문 기업임(가상)
- 회사 소개: 증권·자산운용·저축은행 고객 40여 곳 운영(가상)
- 레퍼런스: A증권 원장 클라우드 전환 완료(가상)
- 일정·비용: 본 자료의 수치와 일정은 협의 결과에 따라 달라질 수 있음
- 일정·비용: 제안 유효기간은 제출일로부터 30일임

## 작성 규칙
- 장 순서는 회사 소개 → 고객 과제 → 서비스 제안 → 레퍼런스 → 일정·비용으로 유지한다
- 본문은 'ㅇ (항목) 내용' 개조식으로 쓰고 문장은 '~임', '~함' 체로 끝낸다
- 일정·비용 장 끝에 유의 문구와 유효기간 문구를 반드시 넣는다
- 제안 유효기간은 제출일로부터 30일로 표기한다
- 비용 단위는 백만원으로 통일하고 단계별 기간은 개월 단위로 쓴다
- 고객 목표는 현재 수치와 목표 수치를 화살표로 함께 제시한다
