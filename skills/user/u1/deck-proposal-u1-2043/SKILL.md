## 작성 규칙
- 문장은 'ㅇ (항목명) 내용' 형식의 개조식으로 쓰고 문장 끝은 '~임', '~함'으로 맺음
- 장 제목은 회사 소개 → 고객 과제 → 서비스 제안 → 레퍼런스 → 일정·비용 순서를 유지함
- 비용 단위는 백만원, 기간 단위는 개월로 통일함

- 현황 문장의 '이(가)'는 앞 단어에 맞춰 조사를 정리해야 함
- 목표는 현재 수치와 목표 수치를 함께 쓰는 정량 표기로 함
