# 보고서 팩

- 상속: corp:koscom-hwp-report. 전사 지침은 그대로 따르고 아래만 덧붙인다.
- 기반 양식: 요약보고 — 전사 한글 스킬의 기본 서식(preset 없음)
- 형식: 한글
- 문체: 전사 보고 문법(명사형 종결 · 2026. 10. 28 · 90자)을 그대로 따른다. 양식별 문체 측정(보고서)도 명사형 100% · 「2026. 4. 23」 꼴 · 항목 평균 40자로 같다.
- 구성(이 순서와 제목 그대로): 개요 → 현황 → 추진 방안 → 사업 예산 → 추진 일정 → 기타 사항

- 제목 박스, 결재라인(담당 · 팀장 · 부서장), 날짜 · 부서 칸, □ 장 제목 모양.

## 고정 문구(글자 그대로)
- (없음)

## 작성 규칙
- 제목은 추진하는 일에 「추진(안)」을 붙여 쓴다(예 - 본사 노후 승강기 제어반 교체 공사 추진(안)).
- 개요는 배경과 목적을 한두 항목으로 요약하고, 근거가 되는 연도별 수치는 * 각주로 단다.
- 현황에는 대상 · 규모와 문제점을 쓰고, 가장 중요한 문제 한 줄은 **굵게** 쓴다.
- 추진 방안에는 무엇을 언제 하는지와 단계 · 우선순위를 쓰고, 세부 조건은 - 하위 항목으로 단다.
- 사업 예산은 합계 금액을 첫 항목에 쓰고, 표(구분 · 소요금액 · 비고, 합계 행)와 단위(예 - 단위 : 억원, 부가세 별도)를 함께 쓴다.
- 추진 일정은 단계별 시기를 표나 항목으로 쓰고, 조정 가능성과 단계 설명은 * 각주로 단다.

## 문체 규칙 (v1.1.0)
한글 스킬의 양식별 문체 측정(`koscom_hangul_skill/templates/voice/보고서`, 대표 문서 1건 · 18줄, 「문체 시험용」)에서 문체 특징만 작성 규칙으로 옮겼다. 종결 · 날짜 · 90자는 전사 보고 문법이 맡는다. 표본이 1건이라 대표 문서를 더 모으면 다시 잰다.
- 줄 끝에 마침표를 찍지 않는다(대표 문서 0%).
- 모든 줄을 명사형으로 맺고(대표 문서 100%) 「~ 실시」 · 「~ 추진」 · 「~ 예정」 꼴을 우선 쓴다.
- 한 항목은 보통 31~49자(평균 40자)로 쓴다. 대상 · 수치 · 시기처럼 이어지는 내용은 짧게 쪼개지 말고 한 항목에 묶는다.
- ㅇ 항목 대부분(대표 문서 78%)에 2~6자 라벨을 붙여 「ㅇ (대상) …」처럼 쓴다.
- 쉼표로 길게 잇지 않는다(쉼표 줄당 0.3개). 나열이 길면 - 하위 항목으로 나눈다.
- 기호는 □ 장 → ㅇ → - → · 순으로 내려 쓰고, 참고는 ※, 근거 수치는 * 각주로 단다.

넣지 않은 측정값: 자주 쓴 라벨 · 표현(활동 인원 · 조직문화 등)은 대표 문서 주제(활동 결과보고)에 묶여 있어 뺐다. 라벨을 붙이는 비율만 옮겼다.
