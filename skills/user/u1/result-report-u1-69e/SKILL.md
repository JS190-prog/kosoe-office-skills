## 작성 규칙
- 제목은 '[사업명] [품목명]- [입찰건명] 제한경쟁입찰(협상에의한계약) 우선협상 결과보고 및 계약체결' 형태로 작성한다.
- 관련근거는 가나다 순으로 문서번호(일자 : 제목) 형식으로 시간순 나열하고, 마지막에 협상결과 통보 메일을 넣는다.
- 본문은 '다음' 이후 1.입찰진행, 2.입찰결과, 3.협상결과, 4.계약체결 순서를 유지한다.
- 금액 단위는 표 우측에 '(단위:원,부가세별도)'로 표기하고, 계약금액은 부가세 포함임을 명시한다.
- 계약보증금은 계약금액의 10/100, 하자보증금은 3/100으로 산정하고 지급각서 대체 여부를 병기한다.
- 지체상금은 지체일수 1일당 계약금액의 1.5/1000으로 기재한다.
