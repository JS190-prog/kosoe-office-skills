# 서식 만들기 안내

이 스킬은 **서식 채우기형**이다. 실제 견적서에서 문서마다 바뀌는 글만 칸으로 비워 둔 서식(.xlsx)에 값을 넣는다. 그래서 원본의 글꼴 · 테두리 · 채우기 · 열 너비 · 행 높이 · 인쇄 설정이 그대로 남는다.

## 칸 토큰

| 모양 | 뜻 |
|---|---|
| `{{이름}}` | `values.json`의 `fields.이름`으로 바뀐다. 같은 이름을 여러 곳에 써도 된다 |
| `{{?이름}}` | `fields.이름`으로 바뀌되, 값이 없으면 **그 행을 통째로 뺀다**(담당자 줄처럼 있어도 되고 없어도 되는 줄) |
| `{{표.열}}` | 이 토큰이 든 행이 반복 행이다. `rows.표`의 건수만큼 행을 복제하고, 각 행의 `열` 값으로 채운다 |
| `{{sum:표.열}}` | `rows.표`의 그 열을 더한 값. `-`와 빈 값은 0으로 본다 |
| `{{#여백}}` | 여백 행 표시(어느 열에 적어도 된다). 반복 행이 늘거나 글이 길어 행이 높아진 만큼 여백 행을 줄여 **전체 높이를 서식과 같게** 맞춘다. 행이 빠져 줄어들면 여백을 늘린다 |
| `{{@이름 WxH+X+Y}}` | 그림 자리. `--image 이름=경로`(또는 `values.json`의 `images.이름`)가 있으면 그 칸의 왼쪽 위에서 X · Y px 떨어진 곳에 W×H px 안으로 비율을 지켜 넣는다. 없으면 비워 둔다 |

- 칸 전체가 토큰 하나이고 그 칸에 숫자 표시 형식이 걸려 있으면, `18,000` 같은 글을 **숫자로** 넣는다(천 단위 쉼표와 0의 `-` 표시가 서식대로 나온다). `-`는 0으로 넣는다.
- `fields`에 이름이 아예 없으면 칸을 비우고 `WARN`을 낸다. 빈 문자열(`""`)은 일부러 비운 칸으로 보고 알리지 않는다.
- 줄 바꿈이 켜진 칸의 글이 길어 줄이 늘면 그 행의 높이를 키운다(줄 수는 열 너비와 글자 크기로 어림한다).
- 복제한 반복 행 사이에는 가는 점선(hair)을 넣는다.

## 바꿈표(tsv)

UTF-8, 탭으로 구분한다. `#`으로 시작하는 줄은 주석이다. 위에서부터 차례로 적용한다.

```
C	B4	{{고객사명}} 귀중
C	B16	{{이용료.대분류}}
C	E17	{{sum:이용료.회사기본}}
C	A23:A34	{{#여백}}
L	○○ 고도화	{{추가업무명}}
P	2	{{@직인}}
```

| 줄 | 뜻 |
|---|---|
| `C <셀 또는 범위> <글>` | 그 칸의 글을 통째로 바꾼다. 범위면 칸마다 넣는다. 글을 비우면 칸을 비운다 |
| `L <찾을 글> <바꿀 글>` | 모든 칸에서 글자 그대로 찾아 바꾼다 |
| `P <그림 번호> -` | 그 그림을 서식에서 뺀다 |
| `P <그림 번호> {{@이름}}` | 그 그림을 빼고, 있던 자리와 크기를 그림 자리 토큰으로 남긴다(직인처럼 서식에 넣으면 안 되는 그림) |
| `S <시트 이름>` | 이 줄부터 그 시트에 적용한다(기본은 첫 시트) |

셀 주소 · 글 · 그림 번호는 `--inspect`로 본다.

```
python scripts/make_template.py --inspect 원본.xls
```

**`C` 줄을 권한다.** `L` 줄에는 실제 고객사명 · 사람 이름을 적어야 하지만, `C` 줄은 셀 주소만 적으므로 바꿈표에 실제 내용이 남지 않는다.

## .xls에서 옮겨지는 것

`make_template.py`는 엑셀 97-2003(.xls)을 읽어 .xlsx로 옮긴다.

- 옮긴다: 칸의 글 · 숫자 · 날짜, 글꼴(이름 · 크기 · 굵게 · 밑줄 · 색), 맞춤 · 줄 바꿈, 테두리, 채우기, 표시 형식, 병합, 열 너비, 행 높이, 용지 · 방향 · 여백 · 한 쪽 너비 맞춤 · 인쇄 영역, 보기 방식, JPEG · PNG 그림(자리는 왼쪽 위 기준, 가로세로 비율 유지)
- 옮기지 않는다: 수식(계산된 값만 온다), 도형 · 글상자 · 차트, 조건부 서식, 이름 정의(인쇄 영역 제외), 메모, EMF · WMF 그림
- 병합된 범위의 테두리는 **범위 바깥 테두리만** 남긴다(범위 안쪽 칸마다 달랐던 테두리는 왼쪽 위 칸 기준으로 맞춘다).

## 서식을 저장소에 넣기 전에

1. `make_template.py`가 마지막에 출력하는 「서식에 남은 글」에 고객사명 · 금액 · 사람 이름 · 전화번호가 없는지 본다.
2. 직인 · 서명 그림은 `P <번호> {{@이름}}`으로 뺐는지 본다. 회사 로고는 남겨도 된다.
3. 원본 문서와 바꿈표는 커밋하지 않는다(`.gitignore`의 `_private/`에 둔다).
4. `form.yaml`의 칸 이름이 서식의 토큰과 같은지 확인한다. `make_template.py`가 「서식에 든 칸」을 출력한다.
5. 가상 값으로 1행 · 여러 행을 만들어 `show.py`와 엑셀 화면으로 확인한다.

## 알려진 한계

- 반복 행 · 뺄 행 · 여백 행이 처음 나오는 행부터 아래를 다시 쓴다. 그 아래에 있는 **그림**은 따라 내려가지 않는다(이 서식의 그림은 모두 위쪽에 있다).
- 여러 행에 걸친 병합이 반복 행 · 뺄 행과 겹치면 만들지 않고 `FAIL`로 끝난다.
- 여백 행을 모두 써도 모자라면 한 쪽을 넘는다(`WARN`). 이 서식은 표 7행까지 한 쪽에 들어간다.
- 줄 수 어림은 글꼴 폭을 재지 않는다. 서식의 글꼴이 PC에 없어 다른 글꼴로 보이면 줄이 한 줄 더 늘거나 줄 수 있다.
