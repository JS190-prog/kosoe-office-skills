# 서식 만들기 안내

이 스킬은 **서식 채우기형**이다. 보고서 스킬(`koscom-hwp-report`)처럼 문단을 조립하지 않고, 실제 문서에서 바뀌는 글만 칸으로 비워 둔 서식에 값을 넣는다. 그래서 원본의 글꼴·줄 간격·표 테두리·쪽 구성이 그대로 남는다.

## 칸 토큰

| 모양 | 뜻 |
|---|---|
| `{{이름}}` | `values.json`의 `fields.이름`으로 바뀐다. 같은 이름을 여러 곳에 써도 된다 |
| `{{표.열}}` | 이 토큰이 든 표의 행이 반복 행이다. `rows.표`의 건수만큼 행을 복제하고, 각 행의 `열` 값으로 채운다 |

- 이름이 아예 없으면 칸을 비우고 `WARN`을 낸다. 빈 문자열(`""`)은 일부러 비운 칸으로 보고 알리지 않는다.
- 토큰은 한 글자모양 구간 안에 있어야 한다. `TemplateMaker`가 그렇게 만들어 준다(글자모양이 바뀌는 자리에 걸친 글도 한 구간으로 합친다).
- 반복 행 위쪽에서 내려오는 세로 병합 칸은 늘어난 행만큼 자동으로 길어지고, 아래쪽 행(합계 등)은 밀린다. 표 높이도 함께 늘린다.

## 바꿈표(tsv)

UTF-8, 탭으로 구분한다. `#`으로 시작하는 줄은 주석이다. 위에서부터 차례로 적용한다.

```
L	(○○ 고도화)	({{추가업무명}})
L	○○증권 주식회사	{{고객사명}}
C	39	2	3	{{이용료.회사기본}}
```

| 줄 | 뜻 |
|---|---|
| `L <찾을 글> <바꿀 글>` | 모든 문단(표 칸 포함)에서 글자 그대로 찾아 바꾼다 |
| `C <문단 번호> <행> <열> <글>` | 그 문단에 든 표의 칸 글 전체를 바꾼다 |

문단 번호와 칸 위치는 `Inspect`로 본다.

```powershell
java -cp "lib\hwplib-1.1.9.jar;scripts\koscom-hwp-fill.jar" Inspect 원본.hwp
```

## 서식을 저장소에 넣기 전에

1. `Inspect 서식.hwp`로 고객사명·금액·사람 이름이 남아 있지 않은지 본다.
2. 한글 파일의 미리보기 글·그림(PrvText · PrvImage)은 `TemplateMaker`가 쓴 파일에 들어가지 않는다(hwplib가 쓰지 않는다). 다른 도구로 만든 서식이면 따로 확인한다.
3. 원본 문서와 바꿈표는 커밋하지 않는다(`.gitignore`의 `_private/`에 둔다).
4. `form.yaml`의 칸 이름이 서식의 토큰과 같은지 확인한다. `TemplateMaker`가 마지막에 「서식에 든 칸」을 출력한다.

## 알려진 한계

- 값이 길어 줄이 늘면 뒤 문단이 밀린다. 쪽 넘김은 한글이 다시 계산한다.
- 표의 반복 행은 행 높이가 같은 단순 행만 다룬다(반복 행 안의 세로 병합은 다루지 않는다).
- 머리말·꼬리말·글상자 안의 토큰은 채우지 않는다(이 서식에는 없다).
