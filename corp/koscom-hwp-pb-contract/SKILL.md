# PB 전산서비스 추가업무 이용 계약서

조항 문장·글꼴·표 모양은 서식 파일에 들어 있다. Claude가 할 일은 **칸에 넣을 값을 모아 `values.json`으로 정리**하고 **렌더러를 돌려 결과를 확인**하는 것뿐이다. 조항 문장을 새로 쓰거나 고치지 않는다.

```
사용자가 준 값 → values.json → scripts/render.ps1 → 계약서.hwp → preview.ps1로 확인 → 전달
```

## 준비물

- Java 8 이상 (`java -version`)
- (권장) 한컴오피스 뷰어 또는 한글 — 결과 확인용
- 이 스킬 폴더를 `<SKILL>`이라 부른다.

## 작업 순서

### 1. 값 모으기

`form.yaml`이 칸의 정본이다. 필수 칸이 빠졌으면 사용자에게 묻는다. 짐작해서 채우지 않는다.

| 칸 | 필수 | 예 | 들어가는 곳 |
|---|:---:|---|---|
| `고객사명` | ✓ | E증권 주식회사 | 표지, 제1조, 서명란("갑") |
| `추가업무명` | ✓ | 고객확인 모니터링 고도화 | 표지 부제, 제2조 |
| `기본계약체결일` | ✓ | 2019.03.15 | 제1조 (YYYY.MM.DD) |
| `계약기간` | | 추가업무 가동 이후 1년간 | 제4조 ① (없으면 이 기본값) |
| `계약일` | | 2026.    .    . | 표지, 서명란 (정해지지 않았으면 연도만) |
| `갑주소` · `갑대표이사` | | 서울특별시 … · 홍 길 동 | 서명란 |
| `을대표이사` | | 김 철 수 | 서명란 |
| `합계` | ✓ | 18,000 | 이용료 표 합계 = 회사기본의 합 |

이용료 표는 `rows.이용료`에 행마다 `대분류 · 중분류 · 소분류 · 회사기본 · 영업점당 · 이용량 · 비고`를 적는다. 금액 단위는 **천원/년, 부가세 별도**다. 값이 없는 금액 칸은 `-`를 넣는다. 행은 몇 개든 된다.

### 2. values.json 쓰기

[`examples/values.example.json`](examples/values.example.json)을 본뜬다.

```json
{
  "fields": {"고객사명": "E증권 주식회사", "추가업무명": "고객확인 모니터링 고도화", "기본계약체결일": "2019.03.15",
             "계약기간": "추가업무 가동 이후 1년간", "계약일": "2026.    .    .", "합계": "18,000"},
  "rows": {"이용료": [{"대분류": "영업지원", "중분류": "AML", "소분류": "고객확인 모니터링 고도화",
                       "회사기본": "18,000", "영업점당": "-", "이용량": "-", "비고": ""}]}
}
```

### 3. 만들기

```powershell
<SKILL>\scripts\render.ps1 -Values values.json -Out 계약서.hwp
```

macOS · Linux: `<SKILL>/scripts/render.sh values.json 계약서.hwp`

표준출력이 `OK <경로>`로 끝나면 성공이다. `WARN [칸] 값이 없어 비워 둠: …`이 나오면 그 칸이 비어 인쇄된다 — 사용자에게 알린다.

### 4. 확인

```powershell
<SKILL>\scripts\preview.ps1 -File 계약서.hwp -OutDir shots
```

캡처에서 볼 것: 표지의 부제와 고객사명, 제1조의 고객사명·기본계약 체결일, 이용료 표의 행 수와 합계, 서명란.

## 하지 않는 것

- 조항 문장을 바꾸지 않는다. 조항이 달라져야 하면 이 스킬의 범위가 아니다 — 서식을 새로 만들어야 한다(아래).
- 금액을 계산해 지어내지 않는다. 사용자가 준 금액만 쓴다. 합계만 회사기본의 합으로 계산한다.
- 실제 고객사명·금액·대표이사 이름을 이 스킬 폴더(예시·평가 자료)에 남기지 않는다. 예시는 모두 가상이다.

## 서식을 고치거나 새 계약서 스킬을 만들 때

`TemplateMaker`가 실제 문서를 칸 토큰이 든 서식으로 바꾼다. 고객사명·금액·사람 이름처럼 문서마다 바뀌는 글을 `{{칸 이름}}`으로 바꾸는 바꿈표(tsv)를 쓰고 돌린다. **원본 문서와 바꿈표는 저장소에 넣지 않는다.**

```powershell
java -cp "<SKILL>\lib\hwplib-1.1.9.jar;<SKILL>\scripts\koscom-hwp-fill.jar" TemplateMaker 원본.hwp 바꿈표.tsv <SKILL>\templates\새서식.hwp
```

바꿈표 형식과 표의 반복 행(`{{표이름.열이름}}`) 규칙은 [`references/template_guide.md`](references/template_guide.md)에 있다. 다른 목적의 한글 문서(공문, 다른 계약서)는 이 폴더를 본떠 **목적마다 스킬을 따로** 만든다.
